# JSON to Dart - macOS 桌面应用

SwiftUI 开发的 macOS 原生桌面应用，用于将 JSON 转换为 Dart 类。

## 功能特性

- ✅ JSON 到 Dart 类的自动转换
- ✅ 支持嵌套对象和多层数组
- ✅ **顶层数组自动生成 `getModelList` 方法**
- ✅ **数组元素类名智能单数化**（users → User）
- ✅ **完整的空安全支持**
- ✅ **默认启用 json_serializable**
- ✅ 自定义类名
- ✅ 两种生成模式：
  - 简单模式：手动 fromJson/toJson
  - json_serializable 模式：使用注解生成（默认）
- ✅ JsonKey 注解支持
- ✅ camelCase 命名转换
- ✅ JSON 格式化
- ✅ 一键复制代码
- ✅ 导出 .dart 文件

## 使用方法

1. **输入 JSON**: 在左侧文本框粘贴 JSON 数据（支持对象或数组）
2. **配置选项**:
   - **类名**: 输入 Dart 类名（默认：AutoGenerated）
   - **使用 json_serializable**: 生成使用 json_annotation 包的代码（默认启用）
   - **JsonKey 注解**: 为字段添加 @JsonKey 注解（仅 json_serializable 模式）
   - **使用 camelCase**: 将 JSON 键名转换为驼峰命名
3. **查看输出**: 右侧自动显示生成的 Dart 代码
   - 如果是顶层数组，会自动生成 `getModelList` 方法
4. **操作**:
   - **格式化**: 美化 JSON 输入
   - **复制**: 复制 Dart 代码到剪贴板
   - **下载**: 保存为 .dart 文件

## 示例

### 示例 1: 对象 JSON

**输入:**
```json
{
  "user_name": "John Doe",
  "age": 30,
  "tags": ["flutter", "dart"]
}
```

**输出（默认 json_serializable + camelCase）:**
```dart
import 'package:json_annotation/json_annotation.dart';

part 'user.g.dart';

@JsonSerializable()
class User {
  @JsonKey(name: 'user_name')
  final String userName;

  final int age;

  final List<String> tags;

  User({
    required this.userName,
    required this.age,
    required this.tags,
  });

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);

  Map<String, dynamic> toJson() => _$UserToJson(this);
}
```

### 示例 2: 数组 JSON（自动生成 getModelList）

**输入:**
```json
[
  {
    "id": 1,
    "name": "Alice",
    "email": "alice@example.com"
  },
  {
    "id": 2,
    "name": "Bob",
    "email": "bob@example.com"
  }
]
```

**输出:**
```dart
import 'package:json_annotation/json_annotation.dart';

part 'user.g.dart';

@JsonSerializable()
class User {
  final String email;
  final int id;
  final String name;

  User({
    required this.email,
    required this.id,
    required this.name,
  });

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);

  Map<String, dynamic> toJson() => _$UserToJson(this);
}

// 顶层数组解析方法
List<User> getUserList(List<dynamic> jsonList) {
  return jsonList.map((json) => User.fromJson(json as Map<String, dynamic>)).toList();
}
```

**使用方法:**
```dart
List<dynamic> jsonList = jsonDecode(response);
List<User> users = getUserList(jsonList);
```
